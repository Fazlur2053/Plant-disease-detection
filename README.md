This work investigates the detection and classification of agricultural diseases using machine learning approaches based on UAV-captured photos. In particular, plant leaf photos taken by UAVs were processed to extract HOG (Histogram of Oriented Gradients) features, which were then fed into a logistic regression classifier. Dimensionality reduction was accomplished using Principal Component Analysis (PCA), while unsupervised learning was accomplished using K-Means clustering. With a classification accuracy of 88.02%, the method shows promise for crop health monitoring using UAVs in real time.
